# 🎡 Tap & Play - Spin the Wheel Game

An interactive spin-the-wheel game with modern design and fun categories!

## 🎮 How to Play

Simply open `index.html` in your web browser and click "Spin the Wheel"!

### Opening the Game:

**Method 1: Direct File Access**
- Double-click `index.html` in your file manager
- Or drag the file into your browser

**Method 2: Browser Open**
- In your browser, press `Ctrl+O` (or `Cmd+O` on Mac)
- Navigate to this folder and select `index.html`

**Method 3: Address Bar**
```
file:///home/user/nfc-game/index.html
```

## ✨ Features

### Visual
- 🎨 Beautiful purple gradient background
- 🎡 Colorful wheel with labeled segments
- ✨ Smooth spinning animations (4 seconds)
- 🎊 Confetti celebration on every spin
- 🎯 Animated bouncing pointer
- 📱 Fully responsive design

### Gameplay
- 🏆 Score system (10-20 points per spin)
- 📜 Spin history tracker (last 10 spins)
- 🔊 Sound effects (Web Audio API)
- 🎲 Four fun categories:
  - ❤️ Compliments (10 points)
  - 🎭 Mystery Dares (20 points)
  - 🍀 Fortunes (15 points)
  - 🤔 Would You Rather Questions (15 points)

### Technical
- 🚫 Button disabled during spin (prevents double-clicking)
- 🎭 Professional glassmorphism UI
- 📊 Real-time score tracking
- 🎨 Smooth fade-in animations
- 📱 Mobile-optimized
